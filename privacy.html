Política de privacidad

MiPeak es una herramienta personal. Esta página explica sus prácticas de datos y el uso de Google Drive; no contiene el historial privado.

Datos y finalidad

Según las fuentes autorizadas, MiPeak puede tratar actividades, tiempos, distancias, vueltas, frecuencia cardiaca, ubicaciones presentes en FIT, sueño, recuperación, objetivos, planes y anotaciones nutricionales o subjetivas. Su finalidad es consultar el historial, analizar sesiones y apoyar la planificación personal. Las estimaciones y las mediciones de dispositivos pueden contener errores.

Acceso a Google Drive

La integración solicita https://www.googleapis.com/auth/drive.file. Puede leer metadatos y contenido, crear o actualizar los archivos que la aplicación crea o que el usuario autoriza para ella. Se utiliza para respaldos cifrados y archivos de actividad seleccionados, no para explorar todo Drive.

MiPeak puede comprobar permisos de sus carpetas de respaldo y aplicar la retención configurada a sus propios archivos. Importar un FIT no requiere modificar el original. Una carpeta compartida no autoriza automáticamente todos sus archivos al cliente OAuth.

MiPeak no vende los datos obtenidos de Google, no los utiliza para publicidad ni para entrenar modelos de IA de propósito general. Su uso y transferencia se ajustan a la Google API Services User Data Policy, incluidos los requisitos de Limited Use.

Almacenamiento y servicios de terceros

El historial se almacena en una base privada en el equipo del usuario o en una tarea privada de Cloud autorizada. Los respaldos para Drive se cifran antes de subirlos; la clave se conserva separada. Las credenciales y tokens se guardan en archivos privados o en el vault correspondiente, nunca en esta web ni en repositorios públicos.

Google procesa los archivos alojados en Drive. Cuando el usuario utiliza ChatGPT o Codex Cloud, los datos necesarios pueden ser tratados por OpenAI conforme a sus condiciones y a la configuración de la cuenta. No se promete que todo permanezca exclusivamente en el PC.

GitHub aloja esta página. No hay formularios, publicidad, analítica propia ni cookies propias. GitHub puede registrar datos técnicos de visitas, como la dirección IP, conforme a su política de privacidad.

Conservación y control

El historial se conserva mientras el usuario lo necesite y los respaldos pueden seguir una retención configurada. El usuario puede revocar la autorización en las conexiones de su cuenta Google y eliminar sus archivos Drive, bases locales y tareas privadas. Revocar OAuth impide nuevos accesos, pero no borra por sí mismo las copias existentes.

Contacto
